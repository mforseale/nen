# Nen

Сайт для самоконтроля: обещания себе, совместные пакты, мысли на пути и личные календари.

Репозиторий: [mforseale/nen](https://github.com/mforseale/nen). `api/` — FastAPI, `web/` — Next.js, `scripts/` — установочные скрипты, `docs/` — архитектура и инструкции. [Правила репозитория и история переноса](docs/repository.md). План дальнейшей автоматизации — [CI/CD](docs/ci-cd-plan.md).

[![CI](https://github.com/mforseale/nen/actions/workflows/ci.yml/badge.svg)](https://github.com/mforseale/nen/actions/workflows/ci.yml)

[CI в GitHub Actions](docs/continuous-integration.md) проверяет API, frontend и production-сборку при push и pull request в `main`. После успешных проверок актуального `main` [автоматический Deploy](docs/automatic-deployment.md) устанавливает готовый пакет на VM и сохраняет одну предыдущую версию. Изменения схемы БД выполняются отдельным проверенным шагом.

## Что работает

- Только собственные и совместные пакты по шести направлениям: Тело, Социум, Дисциплина, Разум, Созидание, Другое. Готового каталога нет. Common — неделя, rare — календарный месяц, epic — календарный год, legendary — всю жизнь.
- Заключение пактов, ежедневные отметки, прогресс и история завершённых обязательств.
- Создание собственных личных пактов: условия, направление и уровень с соответствующим сроком. Они появляются на карте профиля и в списке активных пактов.
- «Отметить все сегодня» в профиле: одна операция для доступных активных пактов. Уже отмеченные и истёкшие пакты пропускаются; чужие отметки не меняются.
- Совместные пакты с собственными условиями и сроком: отправка приглашения, принятие и отказ. Срок начинается после принятия.
- Единый профиль `/people/<логин>` с крупной аватаркой и вкладками «Обзор», «Лента», «Достижения», «Заметки», а у владельца также «Пакты» и управление. `/profile` переводит на свой профиль. В начале обзора — годовые цели; витрины открывают подробности по нажатию. «Мои пакты / История» сворачивается.
- Во вкладке пактов — интерактивная шестиугольная карта с центральным 念 и шестью направлениями по референсу. Выбор направления открывает четыре тира, по три места в каждом, конкретные пакты и их прогресс. Контур направления показывает выполнение сегодня. Поддержана клавиатура и reduced motion.
- До трёх активных пактов одного тира в направлении — общий лимит для своих и совместных пактов. Проверяется сервером у каждого участника; доступны перенос и отмена автором с освобождением мест.
- Форум с постами и обсуждениями, фильтрами «Вся активность / Друзья / Моя» и trending сообщений за неделю. Приватность проверяется сервером. Профиль и форум показывают одни и те же посты.
- Заметки: публичные, по приглашению конкретным пользователям, полностью личные. Создание, редактирование и удаление.
- До 10 календарей с уникальными цветами, общим просмотром и отдельными страницами. У каждого сохраняется одна из трёх тем: классическая, сетка или ежедневник.
- Планирование задач, событий и заметок: дата, время, описание и приоритет; выполнение и возврат задач в план, редактирование, перенос между датами и календарями. Виды «Месяц», «Неделя», «Список», поиск и фильтры. На телефоне по умолчанию открывается список с крупным текстом.
- Поиск по пактам, пользователям и доступным заметкам. Публичные профили.
- Друзья: заявки по логину и из профиля, подтверждение и отказ, отмена заявки, удаление дружбы. Входящие учитываются в уведомлениях.
- Достижения по уровням и темам: 5 пактов с реальными отметками, первый шаг и завершённое обязательство с выполнением не менее 80% дней.
- Годовые цели с числовым прогрессом, выбором года, единицей измерения и видимостью «все / друзья / только я».
- Настройки профиля: имя, описание, цветовой акцент, загрузка и удаление аватарки. В ленте единый формат поста: текст, ссылка и до 10 вложений разных типов. Картинки показываются галереей, музыка — плеерами ниже; без автовоспроизведения. Создание, редактирование, удаление и настройка видимости; прежние записи сохранены.
- До 10 файлов любых типов в закрепе: отдельная загрузка либо закрепление вложения поста. Снятые закрепы остаются в личной библиотеке. До 25 МиБ на файл и 50 МиБ вложений на пост. Для аудио и видео поддержана перемотка; прочие файлы скачиваются.
- Регистрация и HTTP-only сессии. Приватность проверяется на сервере.

## Запуск в Windows

Для нового клона нужны Git, Python 3.10+ и Node.js 24. В PowerShell:

```powershell
git clone https://github.com/mforseale/nen.git
cd nen
python -m venv api/.venv
./api/.venv/Scripts/python.exe -m pip install -r api/requirements.txt
cd web
npm ci
```

Затем открой два терминала в папке проекта (ниже пример для `D:\projects\nen`).

**API:**

```powershell
cd D:\projects\nen\api
.\.venv\Scripts\python.exe -m app.db_admin migrate --backup-dir ..\.local-backups
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

**Сайт:**

```powershell
cd D:\projects\nen\web
npm run dev
```

Открой **http://localhost:3000** и создай профиль через кнопку справа сверху. Для проверки совместного пакта нужны два зарегистрированных пользователя; второму можно войти в другом браузере или приватном окне.

SQLite хранится в `api/pact.db`. Схема обновляется отдельной командой миграции; API при старте проверяет её версию. Для прежней базы без Alembic один раз добавь к команде `migrate` флаг `--adopt-existing`: после проверки структуры будет создана резервная копия и зарегистрирована начальная версия. Аккаунты, посты и файлы сохраняются; вымышленные данные не подставляются. [Миграции и восстановление](docs/database-migrations-and-backups.md).

В новом клоне команда миграции создаёт пустую базу. Пользовательские данные, зависимости, сборки и рабочие `.env` в Git не хранятся.

Next.js передаёт запросы `/api/v1/*` в FastAPI. При другом адресе API задай `NEN_API_ORIGIN` в `web/.env.local` (пример — `web/.env.example`). Для HTTPS-сервера установи `PACT_COOKIE_SECURE=true` в окружении API.

## Проверки

```powershell
cd D:\projects\nen\api
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
cd D:\projects\nen\web
npm test
npm run lint
npm run build
```

Серверные тесты используют отдельную SQLite в памяти и временные файлы. Основной API fixture применяет настоящие миграции; дополнительные тесты проверяют старую схему, rollback, online backup и восстановление. Реальная база не участвует. Frontend-тесты проверяют направления, реальные pact_id, свободные места, сохранение прежних превышений, сегодняшние отметки и прогресс выбранного пакта, а также цели, медиа, друзей и календарь. Production build проверяет TypeScript и рендер маршрутов.
