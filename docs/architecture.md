## Данные и доступ

- Системный каталог имеет стабильные идентификаторы. Common длится 7 дней, rare — календарный месяц, epic — календарный год, legendary — без конечной даты. Дата окончания вычисляется при заключении.
- Заключённый пакт — существующая сущность `Pact`. Дополнительные параметры храним в новой таблице `pact_details`, не меняя и не удаляя существующие записи.
- Совместный пакт создаётся в состоянии draft, получает запрос второму пользователю и становится active только после принятия. Условия и срок фиксируются до отправки. Отказ отменяет пакт. Доступ есть только у участников.
- Дневные отметки уникальны для сочетания пакт / пользователь / дата. Прогресс конечного пакта — доля отмеченных дней от его длительности; для пожизненного показываем количество дней. Браузер передаёт локальную дату и смещение от UTC, сервер сверяет их с текущим временем. Истечение срока проверяется по UTC-времени, а не по локальной дате, чтобы не терять последний день в Томске и других часовых поясах.
- Заметки: public, invited, private. Для invited есть явный список пользователей с доступом; проверки выполняются API. Публичный профиль и поиск не раскрывают почту и закрытые заметки.
- До 10 календарей на пользователя. Цвета уникальны внутри набора. Записи привязаны к календарю и владельцу, общий вид объединяет выбранные календари.
- Комментарии системных пактов образуют публичный форум. Комментарии совместных пактов доступны участникам. Trending считается по числу сообщений за последние 7 дней.
- Любая запись и изменение требуют действующей HTTP-only сессии. Старые незащищённые методы пактов заменяются проверками владельца/участника.

## Изображение и интерактивность

Сердце с цепями — отдельная подробная растровая иллюстрация без нарисованных кинжалов. Кинжалы — индивидуальные SVG-объекты со стабильным `data-pact-id`, построенные только из активных пактов API. В сцене до 8 кинжалов одновременно, остальные доступны постранично; число отображённых совпадает с выбранной страницей активных пактов. Это сохраняет читаемость при любом количестве пактов.

Сердце, цепи и кинжалы находятся в общей медленно пульсирующей группе. Масштаб меняется менее чем на 2%. Наведение/фокус/нажатие выделяет кинжал и открывает доступную карточку; карточка остаётся открытой при переходе курсора на неё. При reduced motion анимации отключаются. Если пактов нет, кинжалов нет.

## Проверка и запуск

API тестируется на отдельной временной SQLite: сессии, приглашения, ежедневные отметки, приватность заметок, лимит календарей и доступ к чужим данным. Frontend проверяется TypeScript и production build; интерактивность и адаптивность — локальным браузером при доступности. Реальные пользовательские данные при проверках не изменяются.

Изменения локальные; внешняя публикация и смена платформы не входят в эту задачу.

## Уточнения от 19 октября 2026

- Условия пакта фиксируются при заключении. Старые небезопасные URL создания и изменения возвращают подсказку использовать каталог или приглашения.
- Проверка лимита календарей и повторного заключения шаблона выполняется внутри блокировки. Ответ на совместное приглашение сохраняется атомарно только из pending; повторное принятие не создаёт ещё одного участника.
- Личные запросы идут через Next.js rewrite `/api/v1` к FastAPI на `127.0.0.1:8000`. Cookie остаётся на домене сайта; адрес API не зашит в браузер как localhost.
- При включённом cacheComponents URL-зависимые компоненты Next.js находятся внутри Suspense, в том числе навигация динамических страниц.
- Browser QA недоступна в текущей сессии: нет подключённого in-app browser или Chrome. Это не заменяется утверждением о визуальной проверке. Выполняются API-тесты, TypeScript, production build, серверный рендер сцены и HTTP-проверки.

## Оформление: уточнение от 19 октября 2026

По обратной связи пользователя убираем мотивационные цитаты и вступительный hero-блок. Главная сразу открывает каталог; названия разделов становятся прямыми и функциональными.

Исходный `nen-bg.jpg` остаётся в проекте и используется внутри main как фоновая иллюстрация каталога. Шапка находится вне области фона и имеет непрозрачную чёрную подложку. Это сохраняет фон, не накладывая изображение на навигацию.

Увеличиваем основной кегль, насыщенность и контраст текста, особенно названий пактов и подписей. Уровни получают более заметные серебристый, синий, фиолетовый и золотой акценты в метках и границах карточек. Не добавляем неоновое свечение.

В навигации текст сопровождается иконками. Поиск при фокусе показывает вертикальные строки категорий: «Пакты», «Пользователи», «Заметки». После выбора категория видна в поле, а результаты появляются ниже списка. Поиск сохраняет прежний API и проверки приватности; поддерживает клавиатуру, Escape и закрытие при выходе фокуса.
