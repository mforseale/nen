# Планирование в календарях — 19 октября 2026

## Сценарии

Календарь хранит события, задачи и заметки на дату. Для событий и задач можно указать время, для событий — время окончания; у записи есть описание и приоритет. Задачу можно выполнить и вернуть в план. Записи можно редактировать, переносить между датами и своими календарями, удалять.

Общий просмотр `/calendars` объединяет выбранные календари. Каждому календарю соответствует самостоятельная страница `/calendars/[id]`, доступная только владельцу. Доступны виды «Месяц», «Неделя» и «Список», фильтры по типу и выполнению. Дневная панель показывает записи выбранного дня и позволяет сразу запланировать новую.

## Совместимость данных

Существующие `calendars` и `calendar_entries` не пересоздаются и не очищаются. Добавляем таблицы `calendar_styles` и `calendar_entry_details` с первичными ключами исходных сущностей. Старые записи без details читаются как заметки; старый календарь без style получает оформление classic. Новые записи создаются вместе с метаданными в одной транзакции. Удаление календаря удаляет его записи и обе группы метаданных.

API возвращает полную модель записи, включая kind, description, start_time, end_time, priority и completed. PATCH сверяет владельца исходного и нового календаря, валидирует итоговую модель. Отметка выполнения допустима только для задач. Время — местное календарное HH:MM, без отправки уведомлений или фонового планировщика. События через полночь разделяются на две записи; окончание в тот же день должно быть позднее начала.

## Оформление

Сохраняем чёрную основу. Цвет календаря применяется к шапке, текущему дню, меткам и границам. На отдельной странице доступен выбор из classic (чёткие панели), grid (акцентная сетка), journal (линейки и более книжная типографика). Настройка сохраняется на сервере вместе с названием и цветом. Тексты календаря крупнее: даты 18–20px, записи 13–15px, основные элементы 14–16px. На узких экранах сетку можно прокрутить; вид «Список» сохраняет полноценную читаемость.

На телефонах по умолчанию открывается «Список», чтобы текст не сжимался до точек. Месяц и неделю можно включить вручную. После переноса записи в другой календарь отдельная страница переключается на него; в общем просмотре календарь записи автоматически добавляется к выбранным.

## Профиль и главная

Заголовок «Системные пакты» убирается визуально; доступный заголовок каталога остаётся для скринридера. Сердце заменяется новой растровой иллюстрацией в рисованной аниме-эстетике HxH: плоский цвет и cel shading вместо реалистичной фактуры. Предыдущие версии изображений сохраняются. Кинжалы остаются самостоятельными SVG, связанными с реальными активными pact_id, и пульсируют вместе с сердцем.

## Проверка

Изолированные API-тесты покрывают создание и редактирование планов, выполнение и возврат задачи, перенос, чужой доступ, наследование старых записей, валидацию времени и удаление. Frontend проверяется production-сборкой и существующими тестами сцены. Браузерная проверка зависит от наличия подключённого браузера.
