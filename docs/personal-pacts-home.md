# Только собственные пакты и главная с шестью направлениями

Решение от 19 октября 2026 года. Заменяет каталог готовых пактов, сохраняя остальные решения из `six-directions.md` и `profile-tabs-and-files.md`.

## Пакты и сохранность данных

- Новые личные пакты создаёт пользователь через `/my/pacts`. Совместные пакты по-прежнему заключаются через приглашение со своими условиями.
- Публичный `/catalog` возвращает пустой список, прежний метод заключения шаблона возвращает 410. Шаблоны больше не предлагаются в интерфейсе и поиске.
- Существующие пакты, отметки, категории, достижения и условия не удаляются и не переписываются. Справочник старых шаблонов остаётся только для определения категории старых записей и названий архивных обсуждений.
- Поиск пактов доступен только среди пактов, участником которых является текущий пользователь. Гостям и другим пользователям приватные условия не выдаются.
- Форум показывает доступные пользователю обсуждения собственных и совместных пактов. Старые публичные обсуждения сохраняются как архив без возможности создавать новые сообщения к шаблону. Приватные обсуждения и trending фильтруются по участию на сервере.

## Главная

Шесть направлений расположены по вершинам шестиугольника: тело сверху, социум слева сверху, дисциплина слева снизу, разум справа сверху, созидание справа снизу, другое снизу. В центре — 念 и переключатель всех направлений. Выбор направления фильтрует реальные активные пакты пользователя и подставляет категорию при создании.

Сохраняется исходное изображение `/nen-bg.jpg`. Рука с цепями занимает правую часть композиции над действиями; изображение ограничено областью main и не заходит на навбар. На узких экранах композиция перестраивается вертикально, подписи и кнопки не уменьшаются до мелкого текста. Линии многоугольника и цветовые акценты сдержанные, без неонового свечения. Мотивационные цитаты не возвращаются.

Лимит остаётся прежним: по 3 активных пакта каждого тира в каждом направлении. На главной показываются только реальные счётчики, пустое состояние предлагает написать собственные условия.

## Проверка

Проверяются отключение шаблонов, создание своих пактов, сохранение старых данных, приватность поиска и обсуждений, позиции направлений и счётчики карты. API-тесты работают на изолированной SQLite. Пользовательская база не используется для тестовых записей.
