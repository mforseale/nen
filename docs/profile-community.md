# Профиль, свои пакты и друзья — 19 октября 2026

Категории, лимиты и порядок разделов уточнены в [six-directions.md](six-directions.md). Остальные правила профиля продолжают действовать.

## Решения

Расширяем текущие Next.js / FastAPI / SQLite без смены платформы. Чёрный фон главной и печать 念 сохраняются. Новые настройки, изображения, темы собственных пактов, дружба, цели и публикации хранятся в добавочных таблицах; существующие таблицы и данные не пересоздаём. Этот документ дополняет architecture.md и pact-seal.md.

- Собственный личный пакт сразу активен. Автор задаёт название, условия, тему и уровень. Длительность соответствует общей системе: common — 7 дней, rare — календарный месяц, epic — календарный год, legendary — без конца. Условия фиксируются при заключении. Пакт закрыт от других пользователей и участвует в существующих отметках и печати; отдельная метка отличает его от каталога. Тема каталожных пактов берётся из каталога, тема старых совместных — «Личное».
- «Отметить все сегодня» — одна транзакция, только активные пакты текущего участника, с серверной проверкой локальной даты, срока, лимита дней и повторной отметки. Чужие отметки и завершение пактов не затрагиваются. Повтор безопасен. Ответ явно сообщает добавленные и пропущенные отметки.
- Дружба двусторонняя: одна уникальная упорядоченная пара пользователей, отправитель, статус pending/accepted/declined. Принять может только получатель; отправитель может отменить запрос, любой друг — удалить дружбу. Повторные и встречные запросы не создают дубликатов. Заявки и список доступны на отдельной странице, входящие учитываются в значке уведомлений.
- Достижения вычисляются из базы, без демоданных. Для каждого тира и темы — 5 различных активных или завершённых пактов хотя бы с одной отметкой именно этого пользователя. Пустые, ожидающие и отменённые обязательства не учитываются. Отдельно — первая отметка и первый завершённый пакт с выполнением не менее 80% дней. Показываем критерий, число и прогресс; публично доступна агрегированная витрина, без названий закрытых пактов.
- Настройки профиля: отображаемое имя, описание, акцент оформления и загрузка/удаление аватарки. Логин и учётные данные этим API не меняются. Изображения ограничены PNG/JPEG/WebP, размером 1 МиБ после подготовки; файлы храним в БД и отдаём отдельными HTTP-ресурсами, без доступа к произвольным путям. Клиент уменьшает изображение до 1200 px (аватар — 512 px). SVG и произвольный HTML не принимаются.
- Годовые цели: год, название, описание, числовая цель, фактический прогресс и единица измерения. Полное создание/изменение/удаление только владельцем. Видимость public/friends/private, по умолчанию private.
- Личная лента/подборка: текстовый пост, картинка, музыка, фильм, книга или ссылка. Текст и подпись, безопасная HTTP(S)-ссылка, при желании загруженная картинка. Без автоматического проигрывания, серверного скачивания чужих URL и iframe. Создание/изменение/удаление только владельцем. Видимость public/friends/private, по умолчанию private.
- Публичный профиль и отдельный ресурс картинки повторно проверяют видимость на сервере. Удаление дружбы немедленно закрывает friends-контент; почта, закрытые цели, записи и файлы посторонним не выдаются. Аватар и описание публичны.

Для пользовательских изображений используем обычный img с запросом непосредственно к API: штатный оптимизатор Next.js не передаёт заголовки сессии к исходнику. Картинки заранее уменьшены клиентом, бинарные данные загружаются ORM только при обращении к файлу; лента и навбар получают метаданные. API файлов отвечает private/no-store и nosniff. В публичном профиле ждём определения сессии перед загрузкой данных, чтобы сразу отобразить правильную видимость для друга или владельца.

## Проверки

API-тесты работают на отдельной SQLite в памяти: создание и сроки своих пактов, отметка всех с повтором/истёкшим сроком/чужими участниками, критерии достижений, состояния дружбы и закрытие доступа после её удаления, владение целями и публикациями, проверка URL и изображений. Интерфейс проверяем TypeScript, production build и доступным браузером; отсутствие браузера явно фиксируем.
