# Оформление репозитория

Решение от 23 октября 2026 года. Уточняет публичное представление проекта из `repository.md`; история репозитория и прежние технические решения сохраняются.

README начинается с описания Nen и скриншота актуальной главной страницы. Скриншот хранится в `docs/images/home.png` и подключается относительной ссылкой, поэтому доступен в клоне без внешнего хостинга. Снимок сделан с публичной гостевой страницы без пользовательских данных, в композиции предоставленного примера.

Общие правила разработки перенесены в `CONTRIBUTING.md`: хранение архитектурных решений, проверки и исключение данных/секретов. Служебные инструкции удалены из публикуемого дерева и списка файлов исходного пакета; их повторная генерация frontend-инструментарием отключена. Технические инструкции по доставке используют роли оператора и CI без привязки к средству разработки.

В `visual-assets.md` сохранена история вариантов иллюстрации и требования к композиции; рабочие текстовые задания заменены описанием принятых визуальных решений. Старые изображения и архитектурные документы не удаляются.

Рабочие базы, данные, конфигурация VM и схема API не изменяются. Секреты и локальные служебные каталоги по-прежнему исключены из Git.
