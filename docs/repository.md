# Общий репозиторий Nen

Решение от 19 октября 2026 года. Первый этап CI/CD — публикация текущего проекта в `https://github.com/mforseale/nen`.

## Структура и история

Единый Git-репозиторий располагается в корне `D:\projects\nen`. Ветка — `main`, remote `origin` — `https://github.com/mforseale/nen.git`. В нём хранятся `api/`, `web/`, `scripts/`, `docs/`, исходные изображения `pictures/` и корневые инструкции. Frontend не является подмодулем или отдельным вложенным репозиторием.

До переноса Git был только в `web/.git`: один коммит `08837a9` (`Initial commit from Create Next App`), ветка `master`, без remotes. Этот исходный коммит сохраняется предком первого общего коммита без переписывания истории. Следующий коммит переносит frontend под `web/` и добавляет остальной проект с накопленными изменениями. Поэтому при просмотре исходного коммита frontend ещё находится в корне — это ожидаемая история переезда.

Перед переносом исходные Git-метаданные и bundle истории сохраняются в локальном `.local-backups/`. Рабочие файлы приложения и пользовательская SQLite не перемещаются и не очищаются. Архив Git остаётся локальным и не попадает на GitHub.

## Содержимое публикации

В Git входят исходники API и frontend, `package-lock.json`, `requirements.txt`, тесты, публичные изображения, примеры настроек, скрипты первоначальной установки и Markdown-документация. Примеры `.env.example` содержат только значения для локального запуска.

Корневой `.gitignore` исключает SQLite и сопутствующие файлы, `.local-backups/`, `.deploy/`, рабочие `.env`, ключи, виртуальные окружения, `node_modules`, `.next`, кэши и локальный JSON-отчёт по данным. `.gitattributes` закрепляет LF в исходниках и shell-скриптах для переносимости Windows/Linux. Существующие исторические иллюстрации и Markdown-решения сохраняются.

До коммита проверяются состав индекса, размер файлов и признаки случайно добавленных секретов. После push проверяются SHA ветки на GitHub и отсутствие вложенного gitlink для `web/`.

При подготовке проверены 132 файла в индексе: вложенных gitlink нет, локальные данные исключены, признаков приватных ключей и типовых токенов не обнаружено. Повторно прошли 60 API-тестов, 32 frontend-теста, frontend lint и `pip check`. Проверка production build от этого же дня описана в [full-verification-2026-10-19.md](full-verification-2026-10-19.md); при переносе Git она повторно не запускалась.

## Граница этого этапа

Публикация исходников не обновляет работающую VM. CI workflow, автоматический deploy, SSH-ключи Actions и переключение production на релизные каталоги на этом этапе не создаются. Следующий этап — CI по [ci-cd-plan.md](ci-cd-plan.md): тесты API, тесты frontend, lint и production build.
