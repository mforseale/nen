# Один профиль и положение фона главной

Решение от 19 октября 2026 года. Заменяет раздел про два URL из `activity-scopes-and-pact-reset.md`.

## Единая страница

Канонический адрес любого профиля — `/people/<username>`. Одна реализация компонента показывает обзор, ленту, достижения и заметки. Для владельца дополнительно доступны пакты, отметка всех, настройки, управление целями, постами и файлами. Для посетителя остаются действия дружбы и предложение совместного пакта.

Отдельная страница кабинета удаляется из реализации. `/profile` остаётся совместимым коротким переходом на адрес текущего пользователя; query и hash сохраняются, включая `?pact=<id>#pacts`. Для гостя этот переход ведёт ко входу. Ссылки интерфейса с известным логином ведут сразу на канонический адрес.

Данные профиля читаются через `/people/<username>` с проверкой зрителя на сервере и `private, no-store`. `/my/profile` остаётся совместимым API настроек и прежних клиентов. `/my/pacts` запрашивается только в профиле владельца. Вкладка пактов не предлагается посетителям; прямой `#pacts` у посетителя открывает обзор. Личные API независимо проверяют сессию и права. Владельцу доступны и собственные заметки, а не вторая страница с другим набором вкладок.

## Фон

Исходный `nen-bg.jpg` сохраняется на всю главную с cover. Фоновый слой сохраняет пропорцию 16:9 и сдвинут на 22% собственной ширины, так что начало руки находится у левого поля независимо от высоты страницы. Минимальная ширина слоя 129% компенсирует этот сдвиг и закрывает правый край страницы. Масштаб схемы и читаемость навигации сохраняются.

## Проверка

Проверяются общий компонент владельца/посетителя, отсутствие личных запросов на чужой странице, набор вкладок, сохранение query/hash старых ссылок, права на данные и production build. Рабочая база после прошлой очистки не используется для тестовых записей и повторно не очищается.

Реализация проверена: 53 API-теста, 32 проверки frontend, TypeScript и production build проходят. Главная, адресуемый профиль и совместимый переход `/profile` отвечают на действующем сервере. В рабочей базе по-прежнему 0 пактов; тестовые данные туда не добавлялись. Визуальная проверка не выполнена: подключённых браузеров в сессии нет.
